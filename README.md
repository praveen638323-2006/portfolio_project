# Praveenkumar's Personal Portfolio

A sleek, responsive, and animated personal portfolio website designed to showcase projects, skills, and photography/creative work. Built using HTML5, CSS3, Bootstrap 5, and Animate.css.

---

## 🚀 Features

- **Responsive Navigation:** A mobile-friendly navbar for seamless section scrolling.
- **Dynamic Hero Section:** A striking introduction with entrance animations and a Call to Action (CTA) button.
- **About Me Section:** A dedicated area detailing professional background, aspirations, and experience.
- **Creative Gallery:** A responsive image grid layout showcasing photography, design assets, or projects.
- **Interactive Contact Form:** A clean contact layout enabling visitors to get in touch.
- **Modern Typography & Styling:** Configured with Google Fonts (Saira) and a dark-overlay hero image for high visual appeal.
- **Fluid Animations:** Smooth, micro-animations powered by Animate.css.

---

## 🛠️ Technologies Used

- **HTML5:** For structured semantic web markup.
- **CSS3:** Custom styles and layouts.
- **Bootstrap v5.3.8:** Responsive grid layout and predefined component styles.
- **Animate.css:** Pre-built cross-browser CSS animations.
- **Google Fonts:** Custom "Saira" typography.

## 💻 Getting Started

### Prerequisites

You only need a modern web browser (such as Chrome, Firefox, Edge, or Safari) to run this project locally.

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/praveen638323-2006/portfolio_project.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd portfolio_project/Portfolio
   ```

3. **Open the project:**
   Simply double-click the `index.html` file or open it using your web browser.
